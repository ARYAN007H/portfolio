About this one

Galleria started with a simple frustration: Linux photo managers are either dated or bloated. Galleria is the answer — a gallery that treats photos like they're worth looking at, with an editing engine (LightCraft) built in.

It ships for Linux, Windows and macOS with full installer coverage, release after release. Portable edits, expressive UI, and a site you can browse in the browser too.

What's in it

  • LightCraft editing engine — portable edits, non-destructive workflow
  • Expressive, modern UI inspired by Material You
  • Full installer matrix: AppImage, .deb, .rpm, .exe, .msi, .dmg
  • Live web presence at aryan007h.github.io/galleria
