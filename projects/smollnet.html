About this one

SmollNet (NetSentry) is a real-time network traffic analyzer with dual anomaly detection engines — statistical and machine-learning — behind a cyberpunk-themed live dashboard.

Scapy-powered packet capture on any interface, rolling Z-score burst detection plus a background-trained Isolation Forest, WebSocket live charts, protocol/IP filters and JSON/CSV export. Docker-ready with host networking.

What's in it

  • Live packet capture (Scapy) on any network interface
  • Dual detection: Z-score bursts + Isolation Forest ML
  • WebSocket cyberpunk dashboard with Chart.js visuals
  • Docker-ready · export sessions as JSON / CSV
