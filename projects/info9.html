About this one

Most OSINT tooling is either a paid SaaS, a pile of scattered scripts, or a bookmark list. Info9 is a single self-hostable workbench that costs nothing to run — every data source is a free public endpoint, computed in your browser.

Geolocation, corporate unwrapping, infrastructure recon, media forensics, sanctions screening: five specialist modules over OpenStreetMap, Shodan InternetDB, GLEIF, RIPEstat, Cloudflare DoH, crt.sh and RDAP.

What's in it

  • Zero API keys — public endpoints + in-browser computation only
  • Five modules: geo, corporate, infra, media forensics, sanctions
  • Self-hostable, AGPL-3.0, CI-verified
  • Built because paid OSINT shouldn't be the only option
