About this one

Archivum is a premium, high-fidelity digital library for the modern web. It pulls from Project Gutenberg and the Internet Archive and wraps it in a reading experience that feels like a bookshop, not a database.

A custom in-memory reading engine loads one chapter at a time (no DOM lag), with dual-page spreads, text-to-speech, customizable typography and a reading tracker. Live at the-archivum.vercel.app.

What's in it

  • Chapter-by-chapter reader — one chapter in memory at a time
  • Dual-page spread layout with horizontal page flips on desktop
  • Text-to-speech, custom typography, offline + reading tracker
  • Live at the-archivum.vercel.app
