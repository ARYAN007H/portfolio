About this one

CodePulse analyzes any local Git repository and produces a self-contained, interactive HTML report visualizing code complexity, churn risk and health metrics. One command, zero config.

Cyclomatic complexity, maintainability index, Git churn, risk scoring — the treemap and table views that tell you where your codebase is actually hurting, before the next refactor does.

What's in it

  • Cyclomatic complexity + maintainability index per file
  • Git churn analysis — which files change (and break) the most
  • Self-contained interactive HTML report, shareable anywhere
  • One command, zero config, any Git repo
